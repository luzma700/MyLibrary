MyLibrary App

Luz Marina Bernales Soloaga

MyLibrary es una aplicación Android desarrollada en Android Studio que permite a los usuarios gestionar su biblioteca personal, reseñar libros y explorar nuevas lecturas.

Características principales
- Registro e inicio de sesión de usuarios
- Visualización de libros guardados
- Publicación y lectura de reseñas
- Sección de perfil personal
- Pantalla de bienvenida (Splash)
- Quines Somos
- Diseño moderno y amigable

## 🛠️ Tecnologías utilizadas
- Lenguaje: Java
- IDE: Android Studio
- Base de datos: SQLite
- Librerías: Retrofit para consumo de API
